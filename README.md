# COPP-RAS (Региональная Аналитическая Система)
Платформа сбора отчетов, ведения мониторингов и агрегации статистики образовательных учреждений ЦОПП Республики Крым.

---

## Быстрый старт

### 1. Локальная разработка (Windows / Linux)
```bash
# Создание виртуального окружения
python -m venv venv

# Активация окружения:
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

# Установка зависимостей:
pip install -r requirements.txt

# Локальный запуск приложения:
python run.py
```
Приложение откроется по адресу `http://127.0.0.1:5000`.

## Развёртывание и обновление на боевом сервере

Подробная архитектура системы и карта каталогов описаны в документе [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

- **Первоначальное развёртывание на Ubuntu 24.04 / 26.04**:
  ```bash
  sudo bash setup_server.sh
  ```
- **Обновление системы на сервере**:
  ```bash
  sudo bash update.sh
  ```
- **Отправка локальных изменений в Git (для разработчика)**:
  ```powershell
  .\quick_push.ps1
  ```
